# Field & Fire — Restaurant Website Concept

A responsive restaurant website concept created by Philip Victor as a self-initiated portfolio project. Field & Fire is fictional; menu items, prices, hours, imagery, and restaurant details are illustrative and are not claims about a real business.

## Preview

Once GitHub Pages finishes deploying, visit:

`https://philipvictor285-lgtm.github.io/Philip-Victor-potfolio/restaurant/`

## Features

- Responsive layout with mobile navigation
- Accessible menu tabs with keyboard support
- Sample seasonal menu and clearly marked concept details
- Reservation request form that prepares an email draft (it does not submit a booking)
- Reduced-motion support and semantic page structure

## Built with

HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.
