# Maison Noire — Fashion Store Concept

A fictional fashion and clothing store created by Philip Victor as a self-initiated portfolio project.

## Preview

https://philipvictor285-lgtm.github.io/Philip-Victor-potfolio/maison-noire/

## Features

- Responsive editorial fashion layout
- Product category filters
- Demo search interaction
- Add-to-bag controls
- Mobile navigation
- Newsletter demonstration
- Clear fictional-project disclosure

## Built with

HTML, CSS, and vanilla JavaScript.

## Disclaimer

Maison Noire, its products, prices, and shopping interactions are illustrative. No real purchases or subscriptions are processed.
