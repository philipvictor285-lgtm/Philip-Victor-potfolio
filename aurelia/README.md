# Aurelia — Luxury Short-Stay Concept

A fictional luxury short-stay property website created by Philip Victor as a self-initiated portfolio project.

## Preview

https://philipvictor285-lgtm.github.io/Philip-Victor-potfolio/aurelia/

## Features

- Responsive luxury property layout
- Stay search interaction
- Coast/city property filters
- Property collection cards
- Accessible mobile navigation
- Enquiry form that prepares an email draft
- Clearly marked fictional details

## Built with

HTML, CSS, and vanilla JavaScript.

## Disclaimer

Aurelia, its properties, locations, prices, and availability are entirely illustrative. The enquiry form does not make or confirm real reservations.
